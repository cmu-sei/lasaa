New snapshot

Freezes the C, C++, and Java source files (and build files) of a directory on this machine. To snapshot a commit instead of the working tree, give its hash, tag, or branch. With a build command, the tree is copied and built first, under bear, so that Clang Static Analyzer (and cppcheck) can use its compile commands; the snapshot then also keeps every file the compiler read, generated ones included.
